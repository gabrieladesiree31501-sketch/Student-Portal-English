# English VI Student Portal

A responsive, static student portal recreated from the provided design.

## Preview

Open `index.html` directly in a browser, or enable GitHub Pages for this repository.

## GitHub Pages setup

1. Open **Settings → Pages**.
2. Under **Build and deployment**, choose **Deploy from a branch**.
3. Select the `main` branch and `/ (root)` folder.
4. Save and wait for GitHub to publish the site.

The demo login accepts any non-empty Student ID and password and opens the sample grade dashboard.
